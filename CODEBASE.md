# Hermod — Codebase Map

## Target Specifications

- **Language:** Go 1.25.0
- **Module:** `github.com/hermod/hermod`
- **Dependency Manager:** Go modules (`go.mod` / `go.sum`)
- **Naming conventions:** `kebab-case` for file and directory names; `PascalCase` for exported types and functions
- **Build tag usage:** `//go:build linux || darwin` and `//go:build windows` for platform-specific socket control

## Physical Path Mappings (Blueprint → Implementation)

### 1. CLI Application Layer
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Root command & global flags | `internal/cli/root.go` | Cobra root, `--verbose`, `--quiet`, `--ipv4`/`--ipv6`, `--version` |
| `serve` command | `internal/cli/serve.go` | Signaling server launcher, cert generation/renewal, GC setup |
| `tx` command | `internal/cli/tx.go` | Send flow: code generation, signaling, handshake, hole punch, QUIC transfer |
| `rx` command | `internal/cli/rx.go` | Receive flow: code parsing, signaling, handshake, hole punch, QUIC receive |
| `trust` command | `internal/cli/trust.go` | Certificate pinning (TOFU + optional fingerprint verification) |
| Version string | `internal/cli/version.go` | Generated version constant (synced by `scripts/bump-version.sh`) |
| Verbosity/logging | `internal/cli/verbosity.go` | Log level parsing, slog configuration, `logInfo`/`logWarn`/`logError`/`logDebug` helpers |
| Cancellation | `internal/cli/cancel.go` | QUIC application error codes and peer-cancel detection |
| Server trust enforcement | `internal/cli/server_trust.go` | `requireTrustedServer()` — aborts if server not pinned |
| Progress bars | `internal/cli/stream_bar.go` | Bouncing shuttle bar for unknown-size (stream) transfers |
| TTY helpers | `internal/cli/tty_unix.go`, `internal/cli/tty_windows.go` | `/dev/tty` opening for SAS prompts |
| Entry point | `cmd/hermod/main.go` | Calls `cli.Execute()` |

### 2. Configuration Manager
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| YAML config load/save | `internal/config/config.go` | `Load()`, `Save()`, `Default()`, config directory resolution |
| TLS config builder | `internal/config/config.go` | `BuildTLSConfig()`, `TLSCurveIDs()`, `TLSCipherSuiteIDs()` |
| Server cert generation | `internal/config/config.go` | `GenerateServerCert()` — self-signed ECDSA P-256, 1-year validity |
| Server cert renewal | `internal/config/config.go` | `RenewServerCert()` — same key, new cert (SPKI preserved) |
| SPKI fingerprint | `internal/config/config.go` | `PubKeyFingerprint()` — SHA-256 of Subject Public Key Info |
| Certificate expiry warnings | `internal/config/config.go` | `LogCertExpiry()` — 90/30/7 day thresholds |
| Server pinning | `internal/config/config.go` | `PinServer()` — store SPKI fingerprint per server URL |

### 3. Cryptographic Engine
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| CPace PAKE (P-256, RFC 9496) | `internal/crypto/crypto.go` | `CPaceInit()`, `CPaceFinish()` — role-bound transcript ordering |
| Hash-to-curve (RFC 9380) | `internal/crypto/hash_to_curve.go` | `hashToCurveP256()` — SSWU map, no timing side channel |
| Hybrid KEM combiner | `internal/crypto/crypto.go` | `DeriveHybridBlobKey()` — SHA-256(kClassical \|\| ssX25519 \|\| ssMLKEM) |
| X25519 ECDH | `internal/crypto/crypto.go` | `GenerateX25519KeyPair()`, `ECDHX25519()` |
| ML-KEM-768 | `internal/crypto/crypto.go` | `GenerateMLKEMReceiverKey()`, `EncapsulateMLKEM()`, `DecapsulateMLKEM()` |
| AES-256-GCM | `internal/crypto/crypto.go` | `SealAAD()`, `OpenAAD()` — channel ID as AAD |
| SAS generation | `internal/crypto/crypto.go` | `SASFromBytes()` — 6 words from EFF Short Wordlist 1 |
| Identicon | `internal/crypto/crypto.go` | `Identicon()` — 8x8 mirrored ASCII art |
| Transfer codes | `internal/crypto/crypto.go` | `GenerateTransferCode()`, `ParseTransferCode()` — EFF wordlist |
| EFF wordlist | `internal/crypto/crypto.go` | `effShortWordlist` — 1,296 entries embedded |

### 5. Signaling Server
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|

| Channel join | `internal/server/server.go` | `handleJoin()` — existence check, duplicate prevention, readiness signal |
| Blob relay | `internal/server/server.go` | `relay()` — forward encrypted blobs, blob count cap |

| Rate limiter cleanup | `internal/server/server.go` | Background goroutine — 30-minute staleness eviction |
| CORS protection | `internal/server/server.go` | `CheckOrigin` rejects browser-origin WebSocket connections |

### 6. Signaling Store
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Store interface | `internal/server/store.go` | `SignalingStore` — allocate, exists, store/fetch blob, failure, delete, purge, close |
| In-memory implementation | `internal/server/store.go` | `MemoryStore` — map-backed with TTL expiry |
| Per-IP channel cap | `internal/server/store.go` | `channelOwners` map — IPv4 /32, IPv6 /64 prefix |
| Background GC | `internal/server/store.go` | `RunGC()` — periodic `PurgeExpired()` |

### 7. UDP Reflection Server
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Reflection endpoint | `internal/server/udp_reflect.go` | `udpReflector` — two-phase HMAC cookie handshake |
| Cookie protocol | `internal/server/udp_reflect.go` | Phase 1: 1-byte probe → 9-byte cookie response. Phase 2: 9-byte echo → 7/19-byte address |
| Key rotation | `internal/server/udp_reflect.go` | Daily HMAC key rotation with 5-minute grace period |
| Rate limiting | `internal/server/udp_reflect.go` | 10 req/s, burst 5 on cookie request phase only |
| Address encoding | `internal/server/udp_reflect.go` | `encodeExternalAddress()`, `DecodeExternalAddress()` — binary format |

### 8. UDP Network Layer
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Packet demultiplexer | `internal/network/network.go` | `packetMux` — first-byte routing (0x01 = probe, else QUIC) |
| UDP socket binding | `internal/network/network.go` | `BindUDP()` — SO_REUSEADDR/SO_REUSEPORT, 2 MiB buffers |
| Hole punching | `internal/network/network.go` | `HolePunch()` — simultaneous probes with nonce discriminators |
| Dual-phase hole punch | `internal/network/network.go` | `HolePunchDual()` — IPv6 preferred (5s), IPv4 fallback (remaining timeout) |
| QUIC dial | `internal/network/network.go` | `DialQUIC()` — client role, SPKI-pinned TLS |
| QUIC listen | `internal/network/network.go` | `ListenQUIC()` — server role, SPKI-pinned TLS |
| Local endpoint enumeration | `internal/network/handshake.go` | `LocalEndpoints()` — non-loopback addresses, family-split |
| Platform socket control | `internal/network/udpcontrol_unix.go`, `internal/network/udpcontrol_windows.go` | Unix: SO_REUSEADDR+SO_REUSEPORT. Windows: no-op |

### 9. QUIC Transport Layer
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| QUIC dial (sender) | `internal/network/network.go` | `DialQUIC()` — `quic.Transport.Dial()` with muxed conn |
| QUIC listen (receiver) | `internal/network/network.go` | `ListenQUIC()` — `quic.Transport.Listen()` with muxed conn |
| TLS configuration | `internal/network/network.go` | ALPN `hermod-p2p`, idle 30s, keepalive 5s, SPKI pinning callback |
| SPKI verification | `internal/network/network.go` | `makeCertPinner()` — constant-time fingerprint comparison |
| Muxed connection wrapper | `internal/network/network.go` | `muxedConn` — implements `net.PacketConn` backed by QUIC channel |

### 10. Transfer Module
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Payload classification | `pkg/transfer/transfer.go` | `ClassifyInput()` — file, text, or stdin stream |
| Metadata serialization | `pkg/transfer/transfer.go` | `EncodeMetadata()`, `DecodeMetadata()` — JSON with kind/name/size/sha256 |
| SHA-256 hashing | `pkg/transfer/transfer.go` | `HashFile()`, `HashBytes()`, `HashStream()` — parallel hash via TeeReader |
| Safe destination path | `pkg/transfer/transfer.go` | `SafeDestinationPath()` — path traversal prevention, dedup suffix |
| Temp file handling | `pkg/transfer/transfer.go` | `TempPath()` — `.hermod_tmp` suffix for atomic rename |

### 11. Rate Limiter
| Blueprint Component | Physical File(s) | Responsibility |
|---------------------|-----------------|----------------|
| Token bucket | `internal/server/ratelimit.go` | `RateLimiter` — per-IP-prefix token bucket |
| HMAC keying | `internal/server/ratelimit.go` | `hashPrefix()` — HMAC-SHA256(daily salt, IP prefix) |
| Salt rotation | `internal/server/ratelimit.go` | Daily UTC rotation with graceful fallback |
| IP prefix extraction | `internal/server/ratelimit.go` | `ipPrefix()` — IPv4 /32, IPv6 /64 |
| Stale cleanup | `internal/server/ratelimit.go` | `Cleanup()` — 30-minute inactivity threshold |

## Build & Deployment

- **Module path:** `github.com/hermod/hermod`
- **Go version:** 1.25.0
- **Version source:** `VERSION` file (root) synced to `internal/cli/version.go` by `scripts/bump-version.sh`
- **Build-time override:** `-ldflags "-X github.com/hermod/hermod/internal/cli.Version=x.y.z"`
- **Release script:** `scripts/build-release.sh`
- **CI/CD:** `.github/workflows/release.yml` (GitHub Actions)

## Configuration Storage

- **Config directory:** `$HOME/.config/hermod` (Linux/macOS), `%APPDATA%/Hermod` (Windows), `/tmp/hermod-<uid>` (fallback)
- **Config file:** `config.yaml` (YAML format, 0o600 permissions)
- **Config env vars:** `HERMOD_LISTEN`, `HERMOD_SERVER`, `HERMOD_DEST_DIR`

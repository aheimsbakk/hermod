Added a `Path(self._path).parent.mkdir(parents=True, exist_ok=True)` guard in `SignalingDB.open()` (`server/db.py`) so the database directory is created automatically on first run. The guard is skipped for `:memory:` paths used in tests. Bumped to v0.5.1.

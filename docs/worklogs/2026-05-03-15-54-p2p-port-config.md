Added `p2p_port: int = 0` to `HermodConfig`, `SenderSession.__init__`, and `ReceiverSession.__init__`; both sessions now pass `port=self.p2p_port` to `PeerListener`. Added `--p2p-port / -P` CLI option to `hermod tx` and `hermod rx`; CLI flag takes precedence over config value. `HERMOD_P2P_PORT` env var and `p2p_port:` YAML key are also supported with integer coercion. Two new integration tests (`TestFixedP2PPort`) verify fixed-port transfers for both sender and receiver roles; all 204 tests pass. Bumped version to 0.6.3.

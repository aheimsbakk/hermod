Whenever code changes affect CLI flags, env vars, behaviour, or public API, update README.md, BLUEPRINT.md, CONTEXT.md, and docs/ in the same commit. Never defer documentation to a follow-up task. This rule is also encoded in AGENTS.md under "Docs with Code".
